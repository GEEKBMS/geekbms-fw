# tools — 主机侧辅助

## 目标能力

| 工具 | 用途 | 状态 |
|------|------|------|
| 寄存器 dump | 经串口/适配器读 DVC1124 `0x00–0x8F` 窗口 | W3 脚本；协议先 UART 文本 |
| YAML/JSON → bin | 保护阈值与串数配置表生成 | W3 格式冻结 |
| CRC8 自检 | 与 `dvc1124_crc8` 交叉验证 | W2 |

## W1 交付

本目录仅 README + 示例配置草稿，避免空目录。

## 示例：`params.example.yaml`

见同目录文件。字段为逻辑名；**不得**填入未公开确认的寄存器地址。

## 安全

dump 工具不得提供「一键全开 FET」类命令。危险操作需显式子命令 + 二次确认（后续实现）。
