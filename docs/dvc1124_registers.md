**来源（必须引用）：**  
[DVC1124 数据手册 V0.6 (PDF)](https://bms.pub/uploads/soft/Datasheet/DVC1124%E6%95%B0%E6%8D%AE%E6%89%8B%E5%86%8C_V0.6.pdf)

**策略：** 本文只记录公开 DS **已出现的功能、位名、量程与总线行为**。  
**具体寄存器字节地址（除总线窗口说明外）在 V0.6 公开摘录中未完整列表化的，一律标 `TBD`，禁止臆造偏移。**

## 1. 器件能力（公开）

| 项 | 公开值 |
|----|--------|
| 串数 | **5–24S**（低于 24S 时未用采样口不可悬空；C0–C4 不可短接） |
| 总压应用叙事 | 锂电池包总压 **不超过约 100 V**；绝对最大 VTOP–VSS 等见 DS |
| FET | 集成电荷泵；**高边**充电/放电 **NFET** 驱动；高边预充/预放 **PFET**；GP 可配低边驱动 |
| 被动均衡 | 片内 MOS；端口电流 **≤ 约 25 mA**；支持外置 NPN；奇偶交替；60 s 均衡定时器 |
| ADC | VADC（电压/温度等）+ CADC（电流，CC1/CC2） |
| 温度 | 内核 ΔVBE；最多 **6** 路外部 10 kΩ NTC（GP1–GP6） |
| 电源模式 | 正常 ~270 μA / 休眠 ~60 μA / 关机 ~1 μA（典型，DS） |
| 封装 | LQFP-48（7×7 mm） |
| LDO | 3.3 V / 50 mA 可供外部 MCU |

## 2. I²C 总线（公开）

| 项 | 公开值 |
|----|--------|
| 速率 | **100 kHz** |
| 角色 | 从机；无时钟延展 |
| 默认地址 | 写 **0x40** / 读 **0x41** → 7-bit **0x20**；支持从机地址硬线配置（细节 **TBD**） |
| CRC8 | 多项式 \(x^8+x^2+x+1\)，初值 **0x00** |
| 寄存器窗口 | 地址 **0x00–0x8F**（共 144 字节）；越界回绕行为见 DS |
| 超时 | 起始后约 **64 ms** 无 STOP 则强制结束传输 |

读写帧格式（DATA 与 CRC 交织）以 DS「通信系统」章节图为准；驱动须按帧实现，不得当裸 SMBus 假设。

## 4. 保护相关（公开语义 · 地址 TBD）

硬件保护（DS）：**COV、CUV、OCC1/OCC2、OCD1/OCD2、SCD**。

| 逻辑名 | 语义 | 阈值范围（公开） | 偏移 |
|--------|------|------------------|------|
| COV / COVT | 电芯过压警报/阈值 | 约 500–4595 mV，步进 1 mV；延时约 200–8000 ms | **TBD** |
| CUV / CUVT | 电芯欠压 | 约 0–4095 mV，步进 1 mV；延时约 200–8000 ms | **TBD** |
| OCD1 / OCD1T | 一级放电过流 | 分流 0.25–63.75 mV，步进 0.25 mV；延时 8–2040 ms | **TBD** |
| OCC1 / OCC1T | 一级充电过流 | 同上量级 | **TBD** |
| OCD2 / OCC2 + OCD2E/OCC2E | 二级过流（硬件比较器） | 约 4–256 mV，步进 4 mV；延时 4–1020 ms | **TBD** |
| SCD / SCDE | 放电短路 | 约 10–640 mV，步进 10 mV；延时至约 1992 μs | **TBD** |
| IWT / IWTS / IWTF | I²C 看门狗 | 超时锁存行为见 DS | **TBD** |

警报多具锁存；清除条件包括写回 0 或对端条件（如 OV 后电压低于 CUV 阈值等）——以实现时对照 DS 原文为准。

第 5–24 串可屏蔽，使对应 OV/UV 定时器禁用（屏蔽寄存器名/偏移 **TBD**）。

## 6. 中断（公开）

可将 GP2/GP3/GP5/GP6 配为中断输出（约 1 ms 低脉冲）。屏蔽位名 DS 出现：**IWM、IVOM、ICCM、ICOM、ICUM、IOC1M、IOC2M、ISCDM**（偏移 **TBD**）。
