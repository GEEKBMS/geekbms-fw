# 架构概览

**仓名：** `geekbms-fw`  
**首发 AFE：** DVC1124  
**首发 MCU：** STM32  
**许可：** Apache-2.0

## 分层

```
┌─────────────────────────────────────────┐
│  apps/demo_16s   UART 遥测 · 配置表      │
├─────────────────────────────────────────┤
│  core/           保护状态机 · 均衡调度    │
│                  事件日志 · SOC 占位      │
├─────────────────────────────────────────┤
│  afe/            afe_driver.h（稳定接口） │
│    └── dvc1124/  寄存器 · I²C · CRC8     │
├─────────────────────────────────────────┤
│  hal/stm32/      i2c · uart · gpio stub  │
└─────────────────────────────────────────┘
         ▲
         │ 主机侧（可选）
┌────────┴────────┐
│ tools/ dump·yaml │
└─────────────────┘
```

## 设计原则

1. **AFE 可插拔：** 应用与 `core` 只依赖 `afe_driver.h`，不直接 include 芯片私有头（除 demo 调试页）。
2. **不臆造寄存器：** 公开 DS 未给出偏移的字段在驱动与文档中标 `TBD` / `NOTIMPL`。
3. **高边叙事写清：** DVC1124 集成电荷泵 + 高边 CHG/DSG NFET 驱动；低边可通过 GP 复用，但 demo 默认高边。
4. **无板可测：** W2 起提供假设备（fake AFE）层，对寄存器打包/解析做单元测。
5. **商用友好许可：** Apache-2.0，便于板厂集成驱动而不强制传染 GPL。

## 数据流（v0.1 目标）

1. `hal_i2c` 与 DVC1124 通信（100 kHz，可选 CRC8）。
2. `afe_dvc1124_*` 读电芯电压 / 保护标志 / 写均衡掩码。
3. `core` 状态机根据阈值决定是否请求关断充/放电路径。
4. `apps/demo_16s` 经 UART 输出一行遥测（CSV 或 JSON）。
5. `tools` 主机脚本做寄存器 dump、YAML→配置 bin（W3+）。

## 与内部实验仓关系

仓库内另有历史实验树（如 N32 端口）**不**并入本公开仓默认构建。公开首发 HAL 锁定 **STM32**；其他 MCU 以 `hal/<mcu>/` 后续追加。
