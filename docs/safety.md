## 风险摘要

| 风险 | 说明 |
|------|------|
| 电击 | PACK 总压可达约 100 V（DVC1124 应用上限叙事） |

| 机械/化学 | 电解液泄漏、爆炸性气体 |

## 强制约束（使用本仓库时）

1. **禁止**将 v0.1 及未经验证构建直接用于道路车辆或载人产品。
2. **禁止**在文档或营销中声称「已通过新国标」「可直接装车」「功能安全已认证」。
3. 台架调试须使用限流电源、合适熔断、灭火器材，并遵守实验室规范。
4. 高边 NFET / 电荷泵控制逻辑错误会导致 PACK+ 失控——改 FET 相关代码前必须双人复核。
5. 被动均衡片内电流上限约 **25 mA**（公开 DS）；大电流外置均衡另议，且不在 v0.1 范围。
