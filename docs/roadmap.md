# Roadmap（30 天 · W1–W4）

时区：Asia/Shanghai。目标：可发 v0.1 tag 的社区可读仓，而非空仓「即将开源」。

| 周 | 产出 | 退出标准 |
|----|------|----------|
| **W1**（本周） | 仓初始化；Apache-2.0；安全免责；`afe_driver.h` RFC；DVC1124 公开字段寄存器笔记；架构/Roadmap；stub 目录 | 本地树完整；文档可独立阅读；API 可评审 |
| **W2** | DVC1124 驱动骨架（I²C + CRC 帧 + 读电压/状态占位）；`hal/stm32` 最小实现或 host 假 I²C；假设备层 | 无板可跑解析单测；真板可 probe 从机地址 |
| **W3** | 保护状态机 v0；均衡 bitmask；UART 遥测；`demo_16s` 可编译；CI 绿灯 | demo 目标编译通过；遥测格式冻结一版 |
| **W4** | docs 补全；README 中英；发 **v0.1** tag；社区征集评估板志愿者；列 v0.2 | tag + 公告草稿；v0.2 议题列表 |

## v0.1 明确不做

- 量产 BOM / 完整 PCB / 认证叙事  
- CAN / BLE / OTA / GPS  
- 主动均衡、精确 SOC/SOH  
- 达锂 / JBD / 极空协议兼容  

## v0.2 候选（不承诺）

- 第二颗 AFE（如 SH367309 或 BQ76952）证明可插拔  
- CAN stub  
- 与手持均衡仪联调协议（增值能力可部分闭源）  
- 参考原理图（非完整量产板）

## 每日节奏建议

至少 1 个可合并改动或 1 篇 docs 更新；禁止长期无提交的「筹备中」状态。
